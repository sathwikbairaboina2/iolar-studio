3. Use Each When
  • List: ordered, changes often, duplicates fine
  • Tuple: fixed data, heterogeneous records
  • Set: uniqueness, membership, set math
  • Dict: key-value mapping, fast lookup by key
  • deque: heavy add/remove at both ends
4. Decision Flowchart

6. Common Mistakes
  • List for membership: O(n), use a set
  • List as a dict key: error, use tuple or str
  • Dict when only unique values needed: use set
  • list.pop(0) as a queue: O(n), use deque
  • Tuple where edits are needed: use a list
